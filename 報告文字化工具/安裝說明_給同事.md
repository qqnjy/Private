# 社群報告總結器 — 安裝說明

這是一個跑在 **Claude 裡面** 的小工具:把週報 `.pptx` 丟進去,或直接貼上後台數據,
它會自動產生我們的週報格式(整體表現總結 / 後續規劃 / 月 KPI 達成表)。

不需要 API key、不用額外付費,用的是你自己 Claude 帳號的額度(會吃 token)。

---

## 怎麼開起來用(每個人做一次)

1. 打開 **Claude**(claude.ai 或桌面/手機 App),開一個新對話。
2. 把附的檔案 **`report_summarizer_in_claude.html`** 上傳到對話裡(用 + 或迴紋針上傳)。
3. 輸入這句話送出:

   > 把這個 HTML 原封不動做成 artifact 開起來,不要改內容。

4. 右邊就會出現工具畫面,直接用即可。

> ⚠️ 注意:這個檔案**雙擊用瀏覽器打開是不會動的**,一定要在 Claude 裡面用上面的方式開,
> 因為它靠的是 Claude 內建的 AI 能力。

---

## 使用步驟

1. 把週報 `.pptx` 拖進去,**或**直接把後台數據貼到下方文字框(兩種都可以,也可並用)。
2. 選設定:報告類型、長度、要不要附日文版。
3. 按「產生總結」。
4. 按「複製」→ 貼進你的週報信件。
   - KPI 表格是 tab 分隔,貼進 Outlook / Word / Excel 會自動變成真的表格。

---

## 小提醒

- 只吃 `.pptx`,舊版 `.ppt` 請先在 PowerPoint 另存成 `.pptx`。
- 純圖片的投影片(文字是圖不是文字框)讀不到字,那頁會顯示「無文字」。
- KPI 的「目標」數字要在你丟進去的資料裡有,工具不會自己編目標。
- 每次「產生總結」會用到你 Claude 帳號的額度。

有問題回報給我,我再調整。
